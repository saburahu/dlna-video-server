# v0.4.5 正式リリース検証の範囲

実行変更はメタデータ照会の8並列化・重複stat削減、PCR管理表の一括更新、Windows atomic置換の限定再試行、番組時間軸の既定値と補完設定の整合に限定。配信本体、番組適格性、旧URL、PCR/PTS、音声64ms監査は変更していません。

型・ビルド・Private/Public全回帰に加え、展開した配布コードで通常Browse/Metadata、旧ID/URL、HEAD/GET、Seek、複数音声、更新・復旧を検査します。実録画はコピーしたキャッシュと読取り専用の元TSを利用し、全編実時間・新たな実機確認とは区別します。manifestのsourceCommit/buildIdと全ファイルSHA256が追跡点です。

Windowsの宛先読取りハンドルを用いた再現、恒久ロック、待機中のソース変更、別種I/Oエラー、停止中の回収を回帰対象としています。一時ファイルや未検証出力を公開せず、一般の再試行間隔や試験期限は変更していません。

性能は同一合成5000物理ファイルを使い、旧版/候補を交互に複数回測定します。待受だけで完了とせず、5000件の一覧と範囲フォルダー内のページ、Metadata、保存済みPCRのGETを確認します。測定値は環境依存で保証値ではありません。初回全編解析終了時刻ではありません。

正式公開前に添付するローカル監査報告・チェックサム一覧を参照してください。既知制限と更新方法は本RCのRelease Notesに記載します。実機で確認済みのv0.4.4の動作を今回新たに全素材へ拡張したとは扱いません。

## 正式版の根拠となるRC1最終実測（Windows、Node 24.22.0、合成5000件）

旧版と候補を交互に各3回、同じ物理ファイル・有効キャッシュで測定。OSキャッシュの強制排除やPC全体の負荷固定は行っていません。

| 指標 | v0.4.4中央値（範囲） | v0.4.5中央値（範囲） |
|---|---|---|
| メタデータ保存済み・待受 | 98.508秒（85.753～107.186秒） | 36.888秒（28.518～39.527秒） |
| 同・最初の正常Browse | 99.287秒（86.658～107.650秒） | 37.411秒（29.349～40.236秒） |
| メタデータ＋PCR保存済み・待受 | 99.664秒（92.236～102.506秒） | 34.981秒（30.955～39.270秒） |
| 同・最初の正常Browse | 100.359秒（92.935～103.453秒） | 35.578秒（31.644～39.849秒） |
| 同・PCR管理API準備 | 117.378秒（111.373～122.260秒） | 39.440秒（35.578～43.459秒） |

全5000件、範囲内25件のBrowse、Metadata、正規化DIDL hash、PCR再生成0のGETを照合。今回の旧版初回約98.5秒等も除外せず保存しています。過去の約38秒や候補15.460秒は今回の保証値として使いません。主要非同期照会はsource stat15000を維持し、cache stat10000→5000、read5000を維持。同期の保存先分離検査も残ります。メタデータ単独の待受RSS中央値は旧版81.86MiB／候補105.30MiB。

キャッシュhit起動の評価であり、5000件の初回全編SI/PCR解析完了時間ではありません。待受だけで起動完了とせず、一覧と再生可能性を別に確認しています。CPU/I/O条件・測定順で実時間は大きく変動し、全環境で同じ短縮率を保証しません。

## 最終回帰

Private757件／Public682件、型チェック・ビルドに成功。Windowsの実読取りハンドルを使った回復・恒久ロック・source変更・I/O異常・停止回収を含みます。検証済み配布物の全hash、展開・標準起動停止・上書き更新・旧版復旧と実HTTPの結果は添付監査報告に記録します。v0.4.4の実機証拠を維持し、新しい実機互換性保証には拡張しません。
