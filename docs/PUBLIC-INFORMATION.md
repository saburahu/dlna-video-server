# 公開情報の方針

DLNA Video ServerはREGZAテレビ・レコーダー向けの互換性を重視する独立した
オープンソースソフトウェアです。メーカー公式の製品・ソフトウェアではありません。
REGZA全製品、または他メーカー製品での動作保証は行いません。

公開文書には利用条件・制限・既知問題を記載し、個人の録画タイトル、実ファイル名、
保存フォルダ、ホスト名、LANアドレス、端末UDN、操作日誌や所有機器一覧は含めません。
具体的な型番は利用者の互換性判断に必要な場合だけ記載し、単なる試験履歴として列挙しません。
調査の詳細は非公開で保管します。過去のGit履歴をこの方針のために書き換えません。

## 技術情報との区別

- 入力codec・sample rate・channel・fps・時計検証・受信能力の条件は残します。
- ソースの受信機判定、プロトコル文字列、既存プロファイルの内部キーは維持します。
  管理画面の互換プロファイル名に含まれる型番は、既存設定を利用者が識別するための表示であり、
  開発者の所有機器一覧ではありません。全機種対応を意味しません。
- テストの通信ヘッダーは受信機実装の合成fixtureとして必要な場合だけ使用します。
  テスト用アドレス・識別子は実機の情報として扱いません。
- 著作権者表記、第三者ライセンスの著作者名、公開プロジェクトのURLは保持します。

## Releaseと配布物

Release Notesもこの方針で作成し、メーカー公式との誤認や対応範囲の誇張を避けます。
配布ビルダーは公開ソースのREADME・CHANGELOG・docsをコピーするため、必ず同じ
監査済みコミットから生成します。生成後はZIPを展開して文書・メタデータを再検査します。
以前のReleaseや添付を黙って差し替えず、新しい配布物を区別します。

既知の音声終端検証失敗、REGZAレコーダーの復帰不能事象、終端Seek制限は隠しません。
PC上の検証成功をテレビの安全な再試行や全機種成功の根拠にしません。
