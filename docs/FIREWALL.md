# Windowsファイアウォール診断

TVにサーバーが出ない場合は、配布フォルダのDiagnose.cmdを実行してください。現在のアプリ／Node絶対パス、設定済みTCPポート、SSDP UDP 1900、LANプロファイル、対象パスの許可・ブロック候補、旧パスの許可、待受件数を読み取り確認します。Setup完了時も同じ診断と案内を表示します。

「許可規則候補あり」は通信保証ではありません。条件付き規則、権限不足、ポリシー、取得失敗は判定不能です。30秒で取得できなければ中断します。UDP 1900を別プロセスも使う場合があるため、待受件数だけでこのDMSが使えているとは判断しません。

Windowsの「セキュリティが強化されたファイアウォール」→「受信の規則」で対象プログラムの絶対パスを確認します。ブロック規則は許可より優先します。必要に応じて利用者自身が対象規則を見直してください。推奨許可は現在のruntime\node.exe・プライベートのみ・リモートIPはローカルサブネット・設定済みTCPポートとUDP 1900のみです。配置先を変更すると旧パスの許可は引き継がれません。信頼できる家庭内LANか確認し、パブリックへの広い許可やFW全体の無効化は避けてください。

規則を自動変更する機能はありません。非管理者／組織ポリシーで取得できない場合はWindows設定画面または管理者PowerShellで確認してください。他社FW、ルーター、IPsec、TVのキャッシュは別途確認が必要です。診断にはローカルパス等が含まれるので公開Issueへ貼る前に個人情報を確認してください。Public管理画面は引き続きlocalhost限定です。
