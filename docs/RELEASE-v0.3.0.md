# DLNA Video Server v0.3.0

**REGZAシリーズのテレビ・レコーダーでの利用を重視した、Windows向けDLNAメディアサーバーです。**

家庭内LANを通じて、PCに保存した動画をDLNA対応機器へ配信できます。必要に応じたリアルタイム変換（JITトランスコード）にも対応しています。

本ソフトウェアはREGZAメーカーの公式製品ではありません。また、すべてのREGZA製品や動画ファイルでの動作を保証するものではありません。

## v0.3.0の主な変更

### 複数音声の再生に対応

AVI、WMV、MKV、MP4の一部の動画について、**2つの音声トラックを維持したままJIT変換・配信できるようになりました。**

対応するREGZA受信機では、再生中に音声トラックを切り替えられます。複数音声JITは、対応する入力形式・音声コーデック・受信機に限定した機能です。互換性を考慮して標準では1音声で配信し、受信機ごとに明示的な許可が必要です。専用の許可登録Web UIはまだありません。

詳しい対応条件と設定方法は[複数音声の説明](https://github.com/saburahu/dlna-video-server/blob/main/docs/MULTI-AUDIO.md)をご覧ください。

なお、Direct Playでは元ファイルの音声トラックを保持しますが、音声の選択・再生可否は受信機の機能に依存します。Direct Play自体は既存機能です。

### JIT変換・再生処理の改善

- 2つの音声トラックについて、時刻情報と終端をそれぞれ独立して検証。
- 対応する2音声JITで、音声が映像より先に終了する場合の映像継続処理を改善。
- Seek要求への応答と、配信処理の診断・検証を改善。未採用の極末尾Seek索引・事前判定は含めません。
- 導入・更新手順とトラブルシューティングの説明を整理。

## 動作環境・インストール

- Windows x64
- Node.js 24.22.0同梱
- FFmpeg／ffprobeは別途用意（検証構成8.1.2）
- 管理画面・管理APIへのアクセスはlocalhost限定

導入方法は[セットアップ](https://github.com/saburahu/dlna-video-server/blob/main/docs/SETUP.md)と[FFmpegの設定](https://github.com/saburahu/dlna-video-server/blob/main/docs/FFMPEG.md)をご覧ください。

旧バージョンから更新する場合は、サーバーを停止してバックアップを取り、新しいアプリを別フォルダへ展開してください。既存のデータ領域を引き継ぐことで、設定・サーバー識別情報・ライブラリ情報などを維持できます。

詳しくは[更新とバックアップ](https://github.com/saburahu/dlna-video-server/blob/main/docs/UPDATE.md)を参照してください。

## 既知の問題・制限

- **動画・機器の互換性：** 古い動画形式や特殊なコーデック構成など、再生できないファイルがあります。すべてのAVI、WMV、MKV、MP4に対応するものではありません。
- **音声の終端処理：** 一部のWMA音声を含むファイルで、再生終了時の時刻整合性検証に失敗する場合があります。
- **REGZAレコーダーでの重大な再生異常：** 特定の動画ファイルの再生後、黒画面から復帰できず、通常の放送表示にも影響した事例があります。原因は特定できていません。同じファイルの再試行を繰り返さないでください。
- **Seekの制限：** 一部の動画では、終端直前の極短い範囲へのSeekが正常に処理できない場合があります。
- **機器ごとの差異：** 音声切替・Seek・再生終了時の動作は、受信機の実装や入力ファイルによって異なります。

詳細は[既知の問題](https://github.com/saburahu/dlna-video-server/blob/main/docs/KNOWN-ISSUES.md)をご覧ください。

---

本バージョンは主にREGZAシリーズでの互換性を考慮して開発・検証しています。REGZA以外のDLNA対応機器でも利用できる場合がありますが、他メーカー製テレビ・レコーダーでの動作は未検証です。VLC向けDirect Playは別経路です。

PC検証と受信機実機確認は別です。新しい配布ZIPそのものを全機種で実機確認したものではなく、探索失敗後の自動復旧も模擬テストによる確認です。
