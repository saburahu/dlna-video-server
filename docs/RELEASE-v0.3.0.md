# DLNA Video Server v0.3.0 — Release Notes案

REGZAテレビ・レコーダー向けの互換性を重視した、家庭内LAN用DLNAメディアサーバーです。
メーカー公式の製品・ソフトウェアではなく、すべての機器やファイルでの再生を保証しません。

## 主な変更

- 対応する受信機と入力構成に限定した2音声JIT。WMV／AVI／MKV／MP4の一部構成で、
  独立したAAC音声トラックを配信します。既定は1音声で、個体別の明示許可が必要です。
- 各音声の時計・開始・終端を独立して監査し、音声終了後に実在する映像の配信を維持します。
- 対応条件、導入手順、トラブルシューティングと既知問題の説明を整理しました。

詳しい入力条件は[複数音声](MULTI-AUDIO.md)を参照してください。音声切替とSeekの動作は
受信機実装・入力ファイルによって異なります。3音声以上のJITや全codec対応ではありません。
Direct Playは元のトラックを保持し、選択・復号はクライアント側の機能です。

## 配布・更新

Windows x64、Node.js同梱、FFmpeg／ffprobe別配置、管理画面・管理APIはlocalhost限定です。
[導入](SETUP.md)、[FFmpeg](FFMPEG.md)、[更新とバックアップ](UPDATE.md)を確認してください。
更新前に停止・バックアップし、新しいアプリを別フォルダへ展開して既存データ領域を指定します。
設定・UDN・catalog・PCR索引を初期化する必要はありません。

## 既知の制限

- 一部の古い音声形式では、自然終了時の時刻整合性検証に失敗する場合があります。
- 一部のREGZAレコーダーと動画ファイルの組み合わせで、再生系が正常に復帰できなくなる
  事象を確認しています。原因は未特定で未解決です。同じファイルの再試行を繰り返さないでください。
- 終端付近の極短いSeekには制限があります。実験的な終端索引・事前判定は含めません。
- 配布ZIPそのものの全機種・全形式での実機検証は行っていません。PC検証と実機の確認範囲は別です。

[既知の問題](KNOWN-ISSUES.md)を確認してください。これは公開前の説明案であり、
Release発行時に対応コミット・ZIP・SHA-256と配布物の検証結果を添えます。
