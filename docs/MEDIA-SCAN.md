# メディア再スキャン

起動・再起動、手動再スキャン、定期更新、録画フォルダ設定変更は、同じ探索処理を使います。
登録したすべての保存先を再帰探索し、TS/M2TS/MTS、MP4/MKV/AVI/WMV/ASFなど既存の対応形式とフォルダ階層を更新します。
画像機能のWebPも従来どおりです。新しいcodec対応を追加したリリースではありません。

ダッシュボードで登録メディア総数、TS/その他動画/画像、最終スキャン時刻、追加/変更/削除件数、状態を確認できます。
「番組一覧」の表はTSの番組情報用です。その他の動画はDLNAの「録画番組→すべて／フォルダ別」で参照します。

## 手動更新と自動更新

「全メディアを再スキャン」は、自動更新の間隔を待たずに全保存先を更新します。
新規導入の自動間隔は30分です。**更新前に保存していた間隔は変更しません。**
ダッシュボードの「自動スキャン間隔（分）」で現在値を確認・変更できます。
未変更の動画はサイズ・更新日時・catalog情報を再利用し、毎回ffprobeや全編PCR解析をやり直しません。
再生中の自動探索/codec解析は延期し、手動探索は協調的に処理します。

## 「探索完了」だけでは再生準備完了とは限りません

- ファイル探索中: 保存先とサブフォルダの追加・変更・削除を確認しています。
- 探索完了: 登録数・フォルダ階層を更新しました。
- codec解析待ち/解析中: 新規・変更動画を既存の低負荷キューで解析しています。
- 保留: 自動処理が無効、または再生を優先して待っています。
- 全処理完了: 探索・必要なcodec解析が完了しました。全機器での再生保証を意味しません。
- エラー: 確認できなかった保存先や解析失敗件数を確認してください。

必要なmetadataと受信条件を検証できるまで、動画の再生resourceは公開しません。
非対応codecや破損ファイルは、探索で登録されても再生候補にならない場合があります。
端末が古い一覧を保持している場合は、テレビ/VLC側で一覧を再取得してください。

## 保存先にアクセスできない場合

HDD/NAS切断、権限エラー、探索失敗では、確認できなかった範囲の既存登録を保護します。
元ファイル削除と断定しません。復旧後に再スキャンしてください。
保存先を設定から明示的に外すと通常一覧から非公開になりますが、元動画やPCRキャッシュは削除しません。
キャッシュを一括削除して解決しようとしないでください。

## 検証範囲

開発環境の8,094動画・423フォルダでは手動探索約9秒、ZP2で再スキャン中の映像/音声継続とSeek成功を確認しています。
これは全HDD/NASや全機種で同じ速度になる保証ではなく、今回の配布ZIPを全機種で再試験した記録でもありません。
新しい配布ZIPは隔離したWindows配置と合成動画で別途検証しています。
管理画面/APIは引き続きサーバーPCのlocalhost限定です。
