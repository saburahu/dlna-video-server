# v0.3.0の配布範囲と検証方針

mainへ検証済みの共通改善を反映し、特殊な動画組み合わせの追加開発を
いったん区切ります。製品バージョンは0.3.0です。

## 含める機能

- 検証済み個体／入力に限定した2音声JIT、安定したPIDとBrowse/GET binding。
- AAC pairの独立監査pipeと、音声終了後に存在する映像の継続。
- 検証範囲を限定したWMA入力policy（既定値は拡大しない）。
- 既存TimeSeekの不正構文・範囲不成立・実行失敗の区別。
- 対応形式・機器実績・未解決事項のドキュメント更新と合成HTTP回帰。

極末尾の新しい索引／事前判定、未解決のWMA時刻補正、診断用の実動画・試験メニューは
含めません。[複数音声](MULTI-AUDIO.md)と[既知問題](KNOWN-ISSUES.md)が適用範囲です。

## 維持する配布仕様

MITと第三者ライセンス、Node.js同梱、FFmpeg/ffprobe別配置、localhost管理を維持します。
開発環境の個体許可、UDN、LAN情報、catalog、キャッシュ、診断ログ、非公開のGit履歴は
取り込みません。既存Release・タグ・ZIPは保持します。

v0.3.0は検証済み機能の正式配布版です。配布ZIPごとに新規導入・既存設定引き継ぎを
隔離検証し、ReleaseへSHA-256と対応ソースコミットを添付します。
新Public ZIP自体の実機未検証、PCと実機の確認範囲の違いを明記します。

## ソース候補の検証

- 型チェック、全502テスト（失敗・skipなし）、ビルド成功。
- 合成MP4/AVI/MKV/WMVの通常HTTP開始・Seek等24区間、Direct Playとの同時配信8確認に成功。
- 合成MKV/MP4の2音声と未許可クライアントの1音声fallbackを10区間確認。
  独立復号・内容差・音声時計/終端、PMT/PID、PCR/TTS、連続性を検証。
- 2本同時JIT、第三要求409、独立/同時Seek置換、停止・後片付けの3シナリオ成功。
  underrun 0、終了後executor 0。既存の時計検証・64ms許容値を維持。
- 隔離した全サーバーでlocalhost管理200、LAN管理API読み書き403、
  Device Descriptionと空のContentDirectory Browseは200。
- 通常TSのcold/warm HTTP、TimeSeek、PCR再利用も自動テスト内の隔離HTTPで確認。

これらは実FFmpeg・HTTPを使ったPC検証です。合成受信機情報による試験を含み、
新しい配布ZIPや全機種のテレビ実機成功を保証するものではありません。
短い合成素材を使う同時配信試験は、その素材の範囲内でSeekします。4K性能試験ではありません。

## 公開文書の監査

REGZA向けの特徴を明示しつつ、機種一覧・個人の試験履歴を一般化しました。
配布へ含める文書は[公開情報方針](PUBLIC-INFORMATION.md)に従います。
[v0.3.0 Release Notes案](RELEASE-v0.3.0.md)も同じ方針で用意しています。
公開ソース337ファイルの許可リスト・機密情報検査に加え、文書の型番・操作時刻混入を検査。
文書の相対リンク70件は参照先が存在します。匿名化後も型チェック、既存502テスト、ビルドが成功し、
追加の公開情報監査テスト1件も成功しました。実装差分はコメントのみで、JITの動作条件は不変です。
過去のRelease説明やGit履歴は書き換えず、次の配布ZIP生成後にも展開内容を再監査します。
