# 更新・バックアップ・アンインストール

1. 全端末の再生を止め、旧版Stop.cmdのStoppedを確認。
2. 旧版Backup.cmdでローカルdataを保存し、バックアップ先を控える。
3. 新版ZIPを別アプリフォルダへ展開する。実行中フォルダに上書きしない。
4. Setup.cmdで同じdata、既存のFFmpeg binを指定。設定・UDN・SQLite catalog・PCR索引を保持する。
5. 起動・一覧・再生を確認し、ログオン自動起動を新版のパスへ更新する。

同じdata/UDNの旧新版を同時に実行しない。旧アプリとバックアップを保持し、戻す場合は停止後バックアップを新しいdata領域へ復元して旧版を起動する。新しいSQLiteを直接古いアプリへ渡さない。

別PCへの置換移行は旧PCを停止し、データのオフラインコピーをimportする。追加PCとして動かす場合は独立UDNを選ぶ。録画のドライブやパス変更ではpath由来ID/索引が変わる場合があるので事前にバックアップする。

削除は停止・自動起動解除後にアプリフォルダを削除する。録画、data、PCR索引、バックアップ、別管理のFFmpegは自動で削除しない。
