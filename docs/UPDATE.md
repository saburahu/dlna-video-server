# 更新・バックアップ・復元・アンインストール

[README](../README.md) ／ [初回設定](SETUP.md)

アプリ、data（設定・UDN・catalog・PCR索引・ログ）、元録画、外部FFmpegは別の保存物です。ZIPの展開し直しだけでdataを初期化する必要はありません。

v0.2.2では全メディア再スキャンを統一しました。新規導入時の自動間隔は30分ですが、既存の保存済み間隔は変更しません。
更新後はダッシュボードで現在値と探索/codec解析状態を確認してください。UDN・ObjectID・catalog・PCRキャッシュの削除は不要です。
Node.js 24.22.0は同梱、FFmpeg/ffprobe 8.1.2は引き続き別配置です。管理画面/APIのlocalhost限定も維持します。

## バックアップ

1. すべての端末の再生を終了します。
2. 利用中のアプリフォルダでStop.cmdを開き、`Stopped` を確認します。
3. 同じフォルダのBackup.cmdを開きます。表示された保存先を控え、設定やSQLite等が保存されたことを確認します。

既定ではdataの親フォルダへ `DLNA-Video-Server-backup-…` を作ります。これは元録画のバックアップではありません。元動画は別途保管してください。停止せずにSQLiteや稼働ロックを手動コピーする方式は避けます。エラーが出た場合は成功と扱いません。

バックアップには個人設定・録画情報が含まれます。Public Issueや公開ファイル共有へ添付しないでください。

## 同じPCで更新

1. 上記の停止・バックアップを行い、旧アプリとバックアップを残します。
2. 新版のWindows ZIPを、**別のアプリフォルダ**へ全展開します。稼働中フォルダへ上書きしません。
3. 新版Setup.cmdのData directoryへ、以前と同じdataの実フルパスを入力します。既存の外部FFmpeg binも指定します。ポートやLAN IPv4を指定していた場合はその値を入力します。
4. 設定済みdataではImportや録画フォルダの質問は省略されます。Setupが起動したら、管理画面、DLNA一覧、代表動画を確認します。Start.cmdで二重起動しません。
5. ログオン自動起動を使う場合は、新版Setupで登録し直します。旧アプリのパスが使われ続けないよう確認します。

同じdata／UDNの旧版と新版を同時に起動しません。サーバー名の変更は個体識別子UDNの変更ではありません。

## バックアップから復元／以前の版へ戻す

1. 現在のサーバーを停止し、自動起動を解除します。
2. 使いたいアプリのSetup.cmdで、**新しい空のdata保存先**を指定します。
3. Import stopped old PC data directoryへ、停止中に作成したバックアップのフルパスを指定します。
4. 旧DMSの停止を確認して `STOPPED` と入力します。置換して同じUDNを保持する質問は、旧サーバーを再稼働しない場合だけ `y` にします。
5. 起動して設定・一覧を確認します。元バックアップは残します。

新版で更新したSQLiteを、そのまま古いアプリで開いて戻す操作は避けてください。旧版のバックアップを別dataへ復元して戻します。

## 別PCへ移行／2台目を追加

旧PCを停止して自動起動も解除し、オフラインバックアップを新PCへコピーします。新PCでは上記Import手順を使います。設定内の録画の絶対パスは自動では書き換わりません。可能なら同じドライブ／NASパスへ接続してから移行します。

録画パスを変える場合は、移行バックアップを残して管理画面で登録先を修正します。パス由来のObjectIDや索引が変わり、端末の記憶位置が引き継がれない場合があります。

**両PCを使い続ける2台目の追加では、UDNを保持せず独立サーバーを選びます。** Importの置換質問は既定の `N` を選び、違うサーバー名を付けます。新規導入でも独立UDNが生成されます。

## アンインストール

全端末の再生を終了→Stop.cmd→Remove-autostart.cmdの順で実行し、停止・解除を確認してからアプリの展開フォルダを削除します。

data、録画、PCR索引、バックアップ、別配置FFmpegは自動では削除されません。再導入・復元に使えるため、不要と確認するまで保持します。録画フォルダをアプリのアンインストール対象にしないでください。


v0.2.3の端末探索復旧については[詳しい説明](CLIENT-DISCOVERY.md)を参照してください。既存の設定・UDN・catalog・PCR索引は保持します。
