# DLNA Video Server v0.4.4 開発候補

正式リリース前の実機確認用候補です。製品バージョンは両版0.4.4。実際のソースSHAとbuildIdはmanifest.jsonを参照してください。

- PT3録画TSからSDT局名・EIT番組情報・予定開始終了を取得し、通常のBrowse/Metadataへ提供します。
- TOT/PCRの録画先頭時計と録画範囲を、EITの放送予定と分離します。dc:dateには検証できた録画先頭、scheduledStart/Endには番組予定を明示JSTで通知し、前後の録画余白を保持します。独立した動的時計機能は追加しません。
- 自動解析は既存PCR制御で低優先度・直列・速度制限付き。再生/Seekを優先し、旧cacheを自動更新します。
- 誤った日時・矛盾するサービス情報は通知せず、恒常的失敗は3回で停止します。詳細はBROADCAST_METADATA.md。

標準DLNA画面への表示は未確認です。受信機によって追加情報を表示しない可能性があります。channelNrの生成、全外字/DRCS、編集TSのsegment別時刻は保留です。内部のTOT/PCR整合性を絶対時刻の精度保証とはしません。

v0.4.3の既知制限（DBRのWMV Seek復帰不安定、AVI冒頭付近Seek、WMA終端、MKV入力警告、Vorbis副音声）も継続します。再生レシピ・安全監査は変更していません。

## 既存環境からの更新

1. Stop.cmdで停止し、Stoppedを確認します。失敗した場合は上書きを進めません。
2. 既存Backup.cmdで運用データのバックアップを取得し、旧アプリフォルダーもコピーして残します。
3. このZIPを既存アプリへ上書きします。既存launcher.jsonとデータフォルダーは保持し、Setupは再実行しません。
4. Start.cmdで起動します。Publicは従来どおり外部FFmpeg/ffprobeが必要です。

## v0.4.3へ戻す場合

RCをStop.cmdで停止し、旧アプリを戻してStart.cmdで起動します。launcher.jsonと現在の運用データは維持します。新cacheは旧版に認識されず、放送情報がファイル名へ戻ることがあります。旧schema 1 cacheは保持しています。追加されたDB列は旧版の既存列を変更しません。

更新後のcatalog行や録画情報を消すため、古いデータバックアップを無条件で上書きしないでください。復旧でデータ復元が必要な場合は、停止後に現在データも保存してから判断します。更新・復旧専用スクリプトは追加していません。
