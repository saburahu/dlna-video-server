# DLNA Video Server v0.4.4

Private／Public共通の正式版です。製品バージョンは0.4.4、採用コミットとbuildIdはmanifest.jsonに記録します。

## 変更

- 平文の放送TSからEIT番組予定、SDT局名、検証済みNITチャンネル情報、TOT/PCRによる録画時計・範囲を取得します。予定時刻と録画範囲を混同しません。
- 安定した録画を既存の低優先度自動解析で処理します。直列、32MiB/s、再生優先、中断・再開、旧キャッシュの補完と安全なfallbackを維持します。Browseで全編解析はしません。
- 適格な録画では番組開始をNPT=0とし、素材ごとの録画前余白を内部で加算します。通常のすべて／フォルダー別は録画1本につき1項目で、新しいフォルダーや準備操作はありません。
- 番組項目はvideoItem、番組開始のdc:date、局名・チャンネル・REGZAサービスID、番組durationを通知します。新ObjectIDと/programme-v1/を使用し、旧ObjectIDと/media/は録画全体の意味を維持します。旧保存位置を新時間軸へ流用しません。
- 完全な対象番組が一意、サービス照合・信頼できる原点・連続PCR・ソース版等の条件が必要です。不確定、途中録画、複数完全番組、時計矛盾などは従来資源へfallbackします。元TSを変更・複製・再エンコードしません。
- 実機確認を踏まえ、本版では適格判定を既定ONとします。保存済み設定は書き換えません。開発検証のprocess環境変数PT3_PROGRAMME_TIMELINE=0でOFFを比較できます。利用者の追加設定は不要です。

## 確認範囲

ユーザーによる製品統合版の確認：X9900Rでは通常フォルダーからの再生、番組名・日時・局名、シーンリスト、期待位置へのシーンジャンプ、通常再生・Seekが成功。DBR-T1010では通常再生と一覧の日時・番組名・局名が成功。DBRのDLNAシーンリスト非対応は今回の不具合とは扱いません。両機の全素材・全編自然終了・未確認の操作まで保証しません。全REGZAへの保証ではありません。

PCのHTTP・TS本文照合・復号・メタデータ・互換性検証は実機表示とは別の証拠です。詳細はPROGRAMME-TIMELINE.md（Publicはdocs内）、BROADCAST_METADATA.md、検証記録を参照してください。

## 既知制限

- TSパケット境界はPES/AAC/GOP境界ではありません。Seek開始のAAC数フレームと仮想番組終端の最終映像に、復号不一致やPES size mismatch/corrupt decoded frame等が残ります。途中の同じ長さの区間でも同種の過渡現象があり、末尾の恒常的境界は別の未確認リスクとして保持します。無警告・完全な境界画質や実機EOFを保証しません。
- 終端ガードは切断位置を後ろへ移すだけで新しい最終境界が残るため、今回の製品レシピへ導入しません。PCR/PTS、64ms監査、JITレシピを変更していません。全編の実時間HTTP再生は今回未実施です。
- 番組原点はTOTの量子化を含む推定です。Content Packetへの切下げによりSeek要求より少し手前へ戻ることがあり、TimeSeekRangeは実位置を通知します。旧whole aliasは解決できますが、現在の一覧へ重複列挙しません。
- 初回補完は総読取量に比例し、大量ライブラリでは長時間かかります。既存5000件起動時の約37～39秒のキャッシュ照会コストは未改善です。30秒起動待ちでは不足する環境があります。
- v0.4.3のDBR WMV Seek復帰不安定、AVI開始直後Seek、WMA Pro自然EOF／WMA v2末尾時計、MKV入力警告、Vorbis副音声未対応を維持します。動的放送時計の独立機能、DRCS完全対応、全ての編集TS対応はありません。

## 更新と復旧

1. Stop.cmdで正常停止を確認し、既存Backup.cmdでデータを保存。旧アプリも残します。
2. v0.4.4 ZIPを既存アプリへ上書きし、launcher.jsonと運用データを保持してStart.cmd。Setupの再実行や追加PowerShell操作は不要です。Publicは既存の外部FFmpeg/ffprobe設定を使用します。
3. 戻す場合はv0.4.4を停止し、旧アプリを戻してStart.cmd。現在の運用データを古いバックアップで無条件に上書きしません。旧版では放送表示がファイル名へ戻る場合があり、新prefixは非対応ですが旧URLは録画全体を維持します。

PrivateはNode/FFmpeg/ffprobe同梱、PublicはNodeのみ同梱でFFmpeg/ffprobe非同梱です。UPDATE.cmd等の独自更新機構、素材・ユーザーデータは追加しません。
