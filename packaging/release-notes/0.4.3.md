# v0.4.3候補 — リリース前整理

通常のMPEG-2 JITへ技術条件に基づくBT.709/limited色正規化を統合。対象受信機経路で適格なMP4を元の通常一覧から再生し、AAC二音声、TimeSeek、接続置換、既存64ms監査を維持します。ソフトウェア変換の全編終了はPCで検証し、通常再生・音声切替・約120秒Seek・Seek後の再切替はユーザーの実機確認済みです。全機種・全素材の保証ではなく、実機の全編終了は未確認です。

役割を終えた「DBR互換性試験」タブ、固定30秒資産の準備・一時公開と専用API/配信URLを撤去。上書きで残った旧ファイルから試験機能は再起動しません。通常のSetup/Start/Stopと既存運用データを維持し、追加設定や手動ファイル削除は不要です。

WMA Pro自然EOF、WMA v2末尾無音契約、既存MKV入力警告・Vorbis副音声等の既知制限は未解決。今回の整理では再生機能を追加・再設計せず、64ms監査や不適格入力拒否を緩めません。正式Releaseは未公開です。
