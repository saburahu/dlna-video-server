# v0.4.3開発候補：受信機別MPEG-2拡張試験

WMA Pro入力と通常AAC2音声を独立した明示許可へ分離しました。両方とも既定無効。現在の要求とendpointを確認した受信機を管理APIから選択します。旧一括mpeg2InputTrialは許可に使用しません。

状態A/B/C、保存値と現在値、再起動後の再照合、オフライン無効化に対応。既存の拒否例外、64ms監査、既知の危険MP4拒否、MPEG-2 TS成功レシピを維持。PS経路は使用しません。Private/Publicの製品バージョンは0.4.3候補です。

新規機能のテレビ実機確認は未実施。WMA Pro自然EOF、WMA v2の音声対応・末尾契約、MKV警告、Vorbis副音声は未解決です。PublicはFFmpeg非同梱です。
